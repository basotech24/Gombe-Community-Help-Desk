DATA & PRIVACY

Before you begin

  • Local by design

    Your information stays in this browser's local storage unless you export it.

  • No account system

    This demo does not provide secure logins or role-based permissions.

  • Back up regularly

    Download a JSON backup before clearing browser data or moving devices.

  • Use sample information

    Avoid storing sensitive personal information or confidential reports.

About this project

A practical offline-first project for learning and open-source collaboration.

HOW TO USE

Quick guide

  1. Record an issue

    Give it a clear title, area, category, priority, and description.

  2. Track progress

    Update the status when action begins or the issue is resolved.

  3. Plan follow-up

    Create a task with an owner and due date.

  4. Protect your data

    Use Backup & Restore to export a copy regularly.

Prototype notice: This is a learning project, not an official government service. It does not contact authorities or guarantee that reported issues will be addressed.
